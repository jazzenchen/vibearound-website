## Release Highlights

Version 0.7.23 adds opt-in multimodal image understanding to API bridge routes. A separate Multimodal settings page selects the vision profile and model, while local attachment caching supports follow-up OCR or detail questions without sending image bytes to text-only target models. Bridge Recorder keeps the multimodal request and response trace separate from the original and translated bridge traffic.

The command-line distribution is published separately as [VibeAround CLI 0.0.12](https://github.com/jazzenchen/VibeAround/releases/tag/va-v0.0.12). Use the desktop links above for the packaged app, and install the current CLI from npm with:

```bash
npm i -g @vibearound/cli
```
