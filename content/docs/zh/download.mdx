## 版本要点

v0.7.23 为 API Bridge 增加了可选的多模态图片理解。独立的“多模态”设置页用于选择视觉 Profile 和模型，本地附件缓存支持在后续轮次继续做 OCR 或细节追问，同时不会把图片字节发给纯文本目标模型。Bridge Recorder 会把多模态请求与响应轨迹和原始、转译后的 Bridge 流量分开记录。

命令行发行包单独发布为 [VibeAround CLI 0.0.12](https://github.com/jazzenchen/VibeAround/releases/tag/va-v0.0.12)。需要桌面应用时用上面的安装包；如果偏好 npm，可以这样安装当前 CLI：

```bash
npm i -g @vibearound/cli
```
